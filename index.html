⚙️ Official AIT Grading System

Standard 10-point scale applied to evaluated percentage in each subject:
Percentage (%) Grade Grade Point Description
90% - 100% O 10.0 Outstanding
80% - 89.9% A+ 9.0 Excellent
70% - 79.9% A 8.0 Very Good
60% - 69.9% B+ 7.0 Good
50% - 59.9% B 6.0 Above Average
40% - 49.9% C / P 5.0 Pass
Below 40% F 0.0 Fail
4-Credit Subject Weighting:
• Theory (CI 1, CI 2, CI 3, End Sem = 100 marks) carries 3 credits weight.
• Practical (25 marks) carries 1 credit weight.
• In progressive mode, if only theory or only practical has been taken so far, the subject grade point is calculated based strictly on the evaluated components!
